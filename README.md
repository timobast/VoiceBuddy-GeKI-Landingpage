## VoiceBuddy-GeKI Landingpage

Standalone Landingpage für **GeKI (Gemeinde‑KI)** – optimiert für **Azure Static Web Apps** (statischer Export).

### Lokal starten

```bash
npm install
npm run dev
```

### Build (Static Export)

```bash
npm run build
```

Der statische Output liegt in **`out/`**.

### Azure Static Web Apps

- **app_location**: `/`
- **output_location**: `out`
- Custom Domain z.B. **`geki.ai-buddy.net`** kann in Azure auf die Static Web App geroutet werden.

### Rechtliches

- **Impressum**: `/impressum`
